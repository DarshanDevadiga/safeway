Project Introduction

The Vehicle Accident Detection Alert System uses advanced IoT hardware including an ESP32 microcontroller, MPU-6500 accelerometer sensor, and a GPS/GSM module. By continuously monitoring the G-force exerted on the vehicle, the system instantly identifies collision patterns.

Upon detecting a critical impact, it automatically extracts real-time precise latitude and longitude coordinates and dispatches SMS alerts to pre-configured emergency contacts (Police, Ambulance, Family). Simultaneously, this web dashboard is updated through the cloud, displaying the live map location and sensor diagnostics to expedite rescue operations.
