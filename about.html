Vehicle Accident Detection Alert System

An IoT and Cloud Integrated Emergency Response Initiative

Abstract

Road traffic accidents claim millions of lives globally. The "Vehicle Accident Detection Alert System" mitigates response delay by automatically recognizing an impact using an MPU-6500 Accelerometer/Gyroscope module. Upon detecting violent acceleration (G-Force threshold breach), it activates the Neo-6M GPS module to lock latitude and longitude coordinates. This localized data is then rapidly transmitted using the SIM800L GSM module via SMS to immediate authorities, while simultaneously publishing the data point to a Firebase NoSQL database to instantly update this web dashboard.

Hardware Architecture

Microcontroller

ESP32 Board: Handles complex multithreading: polling sensors via I2C while managing UART communication for GPS and GSM simultaneously.

Sensor (MPU-6500)

Detects crash impact by measuring rapid changes in 3-axis acceleration and roll-pitch-yaw angles.

GPS (Neo-6M)

Parses NMEA sentences from satellites to provide exact latitude, longitude, and ground speed immediately after the accident.

GSM (SIM800L)

Using AT commands, configures an SMS payload containing emergency texts and Google Maps links to pre-programmed numbers.

Web Application Stack

  • Frontend: HTML5, CSS3 with Glassmorphism UI, JavaScript (Vanilla ES6).
  • Map Integration: Leaflet.js rendering OpenStreetMap and CARTO dark map tiles.
  • Data Visualization: Chart.js for rendering live streaming sensor array data.
  • Backend Interface Ideas (Future Work): Firebase Realtime Database webhook to auto-hydrate DOM dynamically on crash.
